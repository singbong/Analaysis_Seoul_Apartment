## 프로젝트 개요

최근 고금리 및 경기 침체로 인한 주택 가격 하락 속에서도 지역별로 가격 변동폭이 상이하게 나타나는 현상에 주목하였다. 본 프로젝트는 이러한 현상의 원인을 규명하기 위해 서울시 아파트의 공시가격 변화율과 실거래가격에 영향을 미치는 복합적인 요인을 분석하고 예측 모델을 구축하는 것을 목표로 한다.

### 주요 목표

- **공시가격 변화율 예측**: XGBoost 모델을 사용하여 2022년 대비 2023년 공시가격 변화에 영향을 미치는 주요 결정 요인을 식별한다.
- **실거래가격 예측**: GAM (Generalized Additive Model)을 활용하여 실거래가격과 설명 변수 간의 복잡한 비선형 관계를 분석하고 가격 형성 요인을 해석한다.

본 연구의 궁극적인 목적은 주택 시장의 안정성을 확보하고 효과적인 정책 수립에 기여할 수 있는 기초 자료를 제공하는 데 있다.

## 프로젝트 구조

```
Analaysis_Seoul_Apartment/
├── XGBoost/                    # XGBoost 모델링 관련 코드
│   ├── data_merge.ipynb         # 데이터 병합 및 기본 전처리
│   ├── get_lat_lon.ipynb       # 위경도 좌표 획득
│   ├── anc_cart_model.ipynb     # 공시가격 CART 모델
│   ├── trd_cart_model.ipynb     # 실거래가 CART 모델
│   └── visualized.ipynb        # XGBoost 결과 시각화
├── GAM/                        # GAM 모델링 관련 코드
│   ├── other_data_processing.ipynb  # 추가 데이터 전처리
│   ├── visualized_analysis.ipynb    # GAM 결과 시각화
│   └── statistic_analysis(gam).ipynb  # GAM 통계 분석
└── data/                       # 데이터 디렉토리 (저장소 미포함)
```

### 분석 절차

#### XGBoost 분석 흐름
1. **data_merge.ipynb**: 원시 데이터 병합 및 기본 전처리 수행
2. **get_lat_lon.ipynb**: 아파트 주소 기반 위경도 좌표 데이터 확보
3. **anc_cart_model.ipynb**: 공시가격 변화율 예측을 위한 CART 및 XGBoost 모델 구축
4. **trd_cart_model.ipynb**: 실거래가격 예측을 위한 CART 및 XGBoost 모델 구축
5. **visualized.ipynb**: 모델 예측 결과 시각화 및 SHAP 값 기반 중요도 분석

#### GAM 분석 흐름
1. **other_data_processing.ipynb**: 추가 변수 생성 및 데이터 정제 수행
2. **statistic_analysis(gam).ipynb**: GAM 모델 학습 및 통계적 유의성 검정
3. **visualized_analysis.ipynb**: 부분 의존성 플롯(PDP) 등을 활용한 시각화 분석

## 분석 방법론

### 1. 데이터 전처리

#### 이상치 처리
- 실거래가 데이터 중 '차량 120분 이내 접근 가능 시설 수'가 0인 비현실적인 데이터를 식별하여 결측치로 처리하였다.

#### 결측치 처리

| 모델 | 처리 방법 |
|------|----------|
| **XGBoost** | 모델의 자체 결측치 처리 기능을 활용하되, 결측 비율이 10% 이상인 변수는 제외하였다. |
| **GAM** | 결측 비율 0.1% 미만인 관측치는 제거하고, 0.1% 이상인 변수는 분석에서 제외하였다. |

#### 파생변수 생성

- **지형 관련**: 단지 내외의 경사도 및 표고 차이를 변수화하였다.
- **인구 관련**: 2022-2023년 간의 인구수, 인구밀도, 부양비 등의 변화량을 산출하였다.
- **가격 관련**: 전용면적별 평균 공시가격 변화율을 계산하였다.
- **접근성 관련**: 5분에서 30분 단위(5분 간격)의 도보 및 차량 접근 가능 시설 수를 집계하였다.

#### 데이터 변환

- **GAM 모델**: 반응 변수인 실거래가격에 로그 변환(`np.log1p`)을 적용하여 데이터 분포의 정규성을 확보하였다.
- **공시가격 변화율**: `(2023년 공시가격 - 2022년 공시가격) / 2022년 공시가격 × 100` 수식을 통해 산출하였다.

### 2. 모델링

| 모델 | 목적 | 특징 | 평가 지표 |
|------|------|------|-----------|
| **XGBoost** | 공시가격 변화율 예측 | 우수한 예측 성능과 특성 중요도 해석 용이, Early Stopping 적용 | RMSE |
| **GAM** | 실거래가격 예측 | 독립변수와 종속변수 간 비선형 관계 규명에 강점, 평활화 파라미터 최적화 | MSE |

#### XGBoost 모델 설정

- **목표 변수**: 공시가격 변화율 (%)
- **주요 파라미터**: `max_depth` (트리 깊이), `learning_rate` (학습률), `n_estimators` (반복 횟수) 등
- **해석 방법**: SHAP (SHapley Additive exPlanations) 값을 산출하여 변수의 기여도와 방향성을 분석하였다.

#### GAM 모델 설정

- **목표 변수**: 로그 변환된 실거래가격
- **모델 구조**: `GAM(s(X1) + s(X2) + ...)` 형태의 가법 모형
- **하이퍼파라미터**: `lam` (평활화 파라미터), `n_splines` (스플라인 수)
- **해석 방법**: Partial Dependence Plots (PDP)를 사용하여 각 요인의 비선형적 영향력을 시각화하였다.

## 주요 분석 결과

### 1. 공시가격 변화율 (XGBoost)

#### 주요 결정 요인

| 순위 | 요인 | 설명 |
|------|------|------|
| 1 | 세대수 | 단지의 규모를 나타내는 핵심 지표 |
| 2 | 동수 | 단지의 물리적 구성 단위 |
| 3 | 인근 단지 표고 최고값 | 단지 주변의 지형적 특성 |
| 4 | 자치구명 | 행정구역에 따른 지역적 차이 |
| 5 | 노령화지수 | 지역 인구 구조적 특성 |

#### 상세 분석 결과 (SHAP)

- **규모의 영향**: 세대수와 동수는 공시가격 변화율에 부(-)의 영향을 미치는 것으로 나타났다. 즉, 대단지일수록 가격 하락폭이 컸음을 시사한다.
- **지역적 특성**: 서초구, 송파구 등 특정 자치구의 위치 여부가 가격 방어에 중요한 변수로 작용하였다.
- **인구통계학적 요인**: 노령화지수가 높을수록 공시가격 변화율에 정(+)의 영향을 미치는 경향이 확인되었다.

#### 자치구별 변동률

분석 결과, 종로구(-6.3%), 용산구(-7.2%), 서초구(-7.7%) 순으로 하락폭이 작았으며, 노원구(-17.2%) 등 외곽 지역의 하락폭이 상대적으로 크게 나타났다.

### 2. 실거래가격 (GAM)

#### 주요 결정 요인

| 순위 | 요인 | 설명 |
|------|------|------|
| 1 | 차량 15분 이내 접근 가능 시설 수 | 주요 생활 인프라 및 교통 접근성 |
| 2 | 유소년부양비 | 해당 지역의 인구 부양 부담 및 활력도 |
| 3 | 교차집계구노년인구수 | 고령 인구의 거주 분포 |
| 4 | 회전율 | 주택 거래의 빈도 및 시장 유동성 |

#### 가격대별 특성 차이

- **저가 지역 (예: 중랑, 도봉, 구로)**: 유소년 인구수, 노령화지수 등 인구통계학적 요인이 가격 형성에 긍정적인 영향을 미치며, 실거주 중심의 시장 특성을 보인다.
- **고가 지역 (예: 용산, 서초, 강남)**: 환경평가점수, 차량 접근성 등 정주 여건과 인프라가 가격의 주요 결정 요인으로 작용하며, 자산 가치 보전 성격이 강하게 나타난다.

#### 비선형 관계 분석

GAM의 Partial Dependence Plots 분석 결과, 다음과 같은 비선형적인 패턴이 관찰되었다.
- **전용면적**: 일정 크기까지는 가격이 급격히 상승하나, 그 이후에는 증가폭이 둔화된다.
- **경사도 및 접근성**: 특정 구간에서 효용이 극대화되며, 임계값을 초과할 경우 오히려 가격에 부정적이거나 영향력이 포화되는 양상을 보였다.

## 결론 및 시사점

### 주요 결론

본 연구의 분석 결과, 서울시 아파트 가격 형성에는 다음과 같은 요인들이 복합적으로 작용함을 확인하였다.

1. **공통 요인**: 두 모델 모두에서 **교통 인프라(특히 차량 접근성)**와 **인구통계학적 특성**(노령화지수, 부양비)이 가격 결정의 핵심 변수임이 입증되었다.
2. **모델별 차이**: 공시가격은 **단지 규모**와 같은 물리적 특성에 민감하게 반응한 반면, 실거래가격은 지역의 사회경제적 특성과 생활 편의성에 따라 가격대별로 차별화된 패턴을 보였다.
3. **지역적 이질성**: 고가 지역은 환경 및 인프라 요인이, 저가 지역은 실거주 관련 인구통계 요인이 가격을 지지하는 주요소로 나타났다.

### 시사점

- **맞춤형 정책 수립**: 일률적인 정책보다는 지역별, 가격대별 특성을 고려한 핀셋 정책이 요구된다.
- **도시 계획적 고려**: 대규모 단지 조성 시 교통 인프라 확충과 주변 환경 개선을 병행하여 가격 안정성을 도모해야 한다.
- **시장 모니터링 강화**: 공시가격과 실거래가격 간의 괴리, 그리고 이를 유발하는 요인을 지속적으로 모니터링하여 시장의 이상 징후를 조기에 포착할 수 있는 시스템 구축이 필요하다.

본 연구는 단순한 가격 예측을 넘어 주택 가격의 구조적인 요인을 규명함으로써, 보다 과학적이고 합리적인 부동산 정책 수립을 위한 실증적 근거를 제시하였다는 데 의의가 있다.

## 데이터 사용 안내

본 프로젝트에서 활용된 데이터 중 일부는 저작권 및 라이선스 정책에 따라 저장소에 직접 포함되지 않는다.

### 데이터 접근 및 구성

- **공식 경로**: 각 데이터 제공 기관의 공식 플랫폼을 통해 데이터를 확보해야 한다.
- **파일 구조 예시**:
```
data/
├── new_data/
│   ├── apt_hkd_info_2022.csv      # 2022년 공시가격
│   ├── apt_hkd_info_2023.csv      # 2023년 공시가격
│   ├── apt_soc_info_2022.csv      # 2022년 사회통계
│   ├── apt_mst_info_202408.csv    # 아파트 마스터 데이터
│   └── ...
└── make_data/
    ├── df_trd_merged.feather      # 전처리 완료된 실거래 데이터
    └── ...
```
