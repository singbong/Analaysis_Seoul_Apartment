## 🎯 프로젝트 개요

최근 고금리 및 경기 침체로 인한 주택 가격 하락 속에서도, 지역별로 가격 변동폭이 다르게 나타나는 차별적인 현상에 주목했습니다. 본 프로젝트는 이러한 현상의 원인을 파악하기 위해, 서울시 아파트의 공시가격 변화율과 실거래가격에 영향을 미치는 복합적인 요인들을 분석하고 예측 모델을 구축하는 것을 목표로 합니다.

### 🎯 주요 목표

- **📈 공시가격 변화율 예측**: XGBoost 모델을 사용하여 2022년 대비 2023년 공시가격 변화에 영향을 미치는 주요 요인을 식별
- **💰 실거래가격 예측**: GAM (Generalized Additive Model)을 활용하여 복잡한 비선형 관계를 가진 실거래가격을 예측하고, 가격 형성 요인을 해석

> 💡 **궁극적 목표**: 주택 시장의 안정성을 확보하고 효과적인 정책 수립에 기여할 수 있는 기초 자료 제공

## 📁 프로젝트 구조

```
Analaysis_Seoul_Apartment/
├── XGBoost/                    # XGBoost 모델링 관련 노트북
│   ├── data_merge.ipynb         # 데이터 병합 및 기본 전처리
│   ├── get_lat_lon.ipynb       # 위경도 좌표 획득
│   ├── anc_cart_model.ipynb     # 공시가격 CART 모델
│   ├── trd_cart_model.ipynb     # 실거래가 CART 모델
│   └── visualized.ipynb        # XGBoost 결과 시각화
├── GAM/                        # GAM 모델링 관련 노트북
│   ├── other_data_processing.ipynb  # 추가 데이터 전처리
│   ├── visualized_analysis.ipynb    # GAM 결과 시각화
│   └── statistic_analysis(gam).ipynb  # GAM 통계 분석
└── data/                       # 데이터 폴더 (저장소에 포함되지 않음)
```

### 노트북 실행 순서

#### XGBoost 분석 흐름
1. **data_merge.ipynb**: 원시 데이터 병합 및 기본 전처리
2. **get_lat_lon.ipynb**: 아파트 주소 기반 위경도 좌표 획득
3. **anc_cart_model.ipynb**: 공시가격 변화율 예측을 위한 CART/XGBoost 모델 구축
4. **trd_cart_model.ipynb**: 실거래가격 예측을 위한 CART/XGBoost 모델 구축
5. **visualized.ipynb**: 모델 결과 시각화 및 SHAP 분석

#### GAM 분석 흐름
1. **other_data_processing.ipynb**: 추가 변수 생성 및 데이터 정제
2. **statistic_analysis(gam).ipynb**: GAM 모델 학습 및 통계적 분석
3. **visualized_analysis.ipynb**: 부분 의존성 플롯(PDP) 등 시각화 분석

## 🛠️ 분석 방법론

### 1️⃣ 데이터 전처리

#### 🔍 이상치 처리
- 실거래가 데이터에서 '차량 120분 이내 접근 가능 시설 수'가 0인 비현실적인 데이터를 결측치로 처리

#### 📝 결측치 처리

| 모델 | 처리 방법 |
|------|----------|
| **XGBoost** | 모델 자체의 결측치 처리 기능 활용, 결측 비율 10% 이상인 변수만 제거 |
| **GAM** | 결측 비율 0.1% 미만인 관측치는 제거, 0.1% 이상인 변수는 분석에서 제외 |

#### 🔧 파생변수 생성

- **🗺️ 지형 관련**: 단지 내/인근의 경사도 및 표고 차이
- **👥 인구 관련**: 2022-2023년 인구수, 인구밀도, 부양비 등 변화량
- **💰 가격 관련**: 전용면적별 평균 공시가격 변화율
- **🚗 접근성 관련**: 5분/10분/15분/20분/25분/30분 단위로 도보/차량 접근 가능 시설 수 집계

#### 🔄 데이터 변환

- **GAM 모델**: 반응 변수인 실거래가격을 로그 변환(`np.log1p`)하여 데이터 분포를 정규화
- **공시가격 변화율**: `(2023년 공시가격 - 2022년 공시가격) / 2022년 공시가격 × 100` 계산

### 2️⃣ 모델링

| 모델 | 목적 | 특징 | 평가 지표 |
|------|------|------|-----------|
| **XGBoost** | 공시가격 변화율 예측 | 높은 예측 성능과 해석 가능성, Early Stopping 기법 적용 | RMSE |
| **GAM** | 실거래가격 예측 | 비선형 관계 모델링과 해석에 강점, 평활화 지수(lambda) 조절 | MSE |

#### XGBoost 모델 설정

- **목표 변수**: 공시가격 변화율 (%)
- **파라미터** (예시):
  - `max_depth`: 트리 최대 깊이
  - `learning_rate`: 학습률
  - `n_estimators`: 부스팅 반복 횟수
  - `early_stopping_rounds`: 조기 종료 라운드 수
- **해석 방법**: SHAP (SHapley Additive exPlanations) 값을 통해 피쳐 중요도 및 방향성 분석

#### GAM 모델 설정

- **목표 변수**: 로그 변환된 실거래가격
- **구조**: `GAM(s(변수1) + s(변수2) + ...)` 형태로 각 변수의 비선형 효과 모델링
- **하이퍼파라미터**:
  - `lam`: 평활화 파라미터 (lambda) - 과적합 방지
  - `n_splines`: 스플라인 수
- **해석 방법**: Partial Dependence Plots (PDP)를 통해 각 변수의 비선형 영향력 시각화

## 📊 주요 분석 결과

### 1️⃣ 공시가격 변화율 (XGBoost)

#### 🎯 주요 영향 요인

| 순위 | 요인 | 영향력 설명 |
|------|------|-----------|
| 1 | 세대수 | 단지 규모의 핵심 지표 |
| 2 | 동수 | 물리적 규모 특성 |
| 3 | 인근 단지 표고 최고값 | 지형적 특성 |
| 4 | 자치구명 | 지역별 시장 차이 |
| 5 | 노령화지수 | 인구통계학적 요인 |

#### 📈 SHAP 분석 결과

| 요인 | 영향 방향 | 설명 |
|------|-----------|------|
| **세대수/동수** | 음(-) 영향 | 단지 규모가 클수록 공시가격 변화율에 부정적 영향 (대형 단지의 하락폭이 큼) |
| **지역 특성** | 양(+) 영향 | 서초구, 송파구 등 특정 자치구 여부가 중요한 변수 |
| **노령화지수** | 양(+) 영향 | 노령화지수가 높을수록 공시가격 변화율에 긍정적 영향 |

#### 📍 자치구별 공시가격 변화율 순위

| 순위 | 자치구 | 평균 변화율(%) |
|------|--------|--------------|
| 1 | 종로구 | -6.3 |
| 2 | 용산구 | -7.2 |
| 3 | 서초구 | -7.7 |
| ... | ... | ... |
| 25 | 노원구 | -17.2 |

### 2️⃣ 실거래가격 (GAM)

#### 🎯 주요 영향 요인

| 순위 | 요인 | 영향력 설명 |
|------|------|-----------|
| 1 | 차량 15분 이내 접근 가능 시설 수 | 교통 인프라 접근성 |
| 2 | 유소년부양비 | 인구통계적 요인 |
| 3 | 교차집계구노년인구수 | 지역 인구 구조 |
| 4 | 회전율 | 시장 활동성 지표 |

#### 🏘️ 가격대별 특성 비교

| 구분 | 지역 예시 | 주요 영향 요인 | 특징 |
|------|-----------|---------------|------|
| **저가 지역** | 중랑, 도봉, 구로 | 유소년 인구수, 노령화지수 | 인구통계학적 요인이 긍정적 영향, 실거주 수요 중심 |
| **고가 지역** | 용산, 서초, 강남 | 환경평가점수, 차량 접근성 | 자산 투자적 성격이 강함, 환경/인프라 중시 |

#### 📊 비선형 관계 발견

GAM의 Partial Dependence Plots을 통해 다음과 같은 비선형 관계를 확인:
- **전용면적**: 일정 구간까지는 가격 상승, 그 이후에는 완만한 증가
- **인근 경사도**: 적절한 경사도 구간에서 가격 최대, 과도한 경사도에서 가격 하락
- **차량 접근성**: 15분 이내 접근 시설 수가 일정 수준까지는 가격 상승, 그 이후에는 포화

## 💡 결론 및 활용 방안

### 🎯 주요 결론

#### 🔗 공통 요인
- 두 모델 모두에서 **교통 인프라(특히 차량 접근성)**의 중요성이 확인
- **인구통계학적 요인** (노령화지수, 부양비)이 가격 형성에 영향

#### 🔄 차별적 요인
- **공시가격**: 단지 규모(세대수, 동수)와 물리적 특성에 큰 영향
- **실거래가격**: 인구 구조, 생활 편의성, 자산 가치 등 지역의 사회경제적 특성에 따라 가격대별로 다른 패턴

#### 📍 지역별 인사이트
- **고가 지역**: 환경평가점수, 차량 접근성이 핵심 요인 → 투자 관점에서 가치 평가
- **저가 지역**: 유소년 인구, 노령화지수가 중요 → 실거주 수요 관점에서 가치 평가

### 🚀 활용 방안

#### 📋 정책 수립 지원
- 지역별, 가격대별 특성을 고려한 맞춤형 부동산 정책 설계
- 세대수, 동수 등 단지 규모가 시장에 미치는 복합적 영향을 고려한 공급 정책 개발
- 교통 인프라 확충이 지역별 주택 가격에 미치는 영향 고려

#### 📊 시장 예측 및 리스크 관리
- 금리 변동과 같은 거시경제 충격 발생 시, 단지 특성별 예상 가격 변동률 산출
- 실거래가격의 적정 수준을 평가하고 이상 거래를 탐지하는 모니터링 도구로 활용
- 공시가격과 실거래가격의 괴리를 분석하여 시장 과열/냉각 신호 파악

#### 🔍 종합적 시장 분석
- 공시가격과 실거래가격 모델을 상호보완적으로 활용하여 시장을 다각도로 분석
- XGBoost의 예측력과 GAM의 해석력을 결합하여 정확도와 설명력 모두 확보
- 지역별, 단지별 맞춤형 가격 분석 및 예측 시스템 구축
